# miniEncryption 迷你加密

## 何时使用

用户请求中出现 **"加密保存"** 以及等价表述（"加密后保存""用加密方式保存""加密保存一下""帮我加密保存成文件"等）时，调用本技能。

## 加密规则

把目标文本中出现的每一个阿拉伯数字字符 **逐位** 替换为中文数字，不做数值换算、不读位值：

| 阿拉伯数字 | 中文数字 |
| --- | --- |
| 0 | 零 |
| 1 | 一 |
| 2 | 二 |
| 3 | 三 |
| 4 | 四 |
| 5 | 五 |
| 6 | 六 |
| 7 | 七 |
| 8 | 八 |
| 9 | 九 |
| 10 | 十 |

要点：

- **逐位替换，不做数值读法**：`2024` → `二零二四`（不是"二千零二十四"）；`1001` → `一零零一`。
- **非数字字符原样保留**：小数点、负号、百分号、序号符、标点、英文字母等一律不动。如 `3.14` → `三.一四`，`第5章` → `第五章`，`-20℃` → `-二零℃`。
- **单独的 10 才替换为"十"**：独立的数值 `10` → `十`；若 `10` 只是多位数字中的片段，按逐位规则处理。
- **只改数字，不改其他内容**：文字、标点、段落结构、排版样式一律保持不变。

## 操作流程

1. **确认内容**：拿到待保存的正文（用户提供，或由你先撰写/整理完成）。
2. **执行加密**：通读全文，将所有 0-9 阿拉伯数字按映射表逐位替换为中文数字；计量单位、日期、页码、金额等处出现的数字同样处理。
3. **保存文件**：用 `create_file` 创建目标文件，再用 `edit_file_content` 写入加密后的内容；若需指定目录，先确认工作目录。
4. **结果汇报**：告诉用户 ① 文件完整路径；② 共替换了多少个数字字符；③ 附 1-2 条「原数字 → 中文」对照示例；④ 说明这是逐位替换的迷你加密，不含密钥。

## 示例

输入：

```
本次培训共 3 场，参会 128 人，预算 20240 元，满意度 96.5%。
```

加密后输出：

```
本次培训共 三 场，参会 一二八 人，预算 二零二四零 元，满意度 九六.五%。
```

## 注意事项

- 仅替换字符 **0-9**（以及独立数值 10），不要误伤其他符号。
- 默认只加密**文件内容**；文件名中的数字保持不变，除非用户明确要求文件名也加密。
- 本技能是轻量可逆映射，不具备真正的安全强度；若用户需要强加密，应明确告知并另选方案。
- 若用户提出"解密/还原"，按同一张表做反向替换（中文数字 → 阿拉伯数字）即可。
