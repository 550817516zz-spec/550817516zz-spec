# 2026-10-29

## xAgent Connection error 修复

### 根因
1. **端口 7863 无服务监听**：config.ini 中 base_url 指向 `http://127.0.0.1:7863/v1`，但该端口无任何服务监听（netstat 确认，errno=10061 connection refused）
2. **httpx 代理劫持 localhost**：httpx 默认 `trust_env=True`，读取 `HTTP_PROXY/HTTPS_PROXY` 环境变量且不自动绕过 loopback，导致 127.0.0.1 请求被转发到系统代理
3. **错误信息双重前缀且无信息量**：openai_client.py 抛 `LLMError(f"模型请求失败：{exc}")`，engine.py 再包 `f"模型请求失败：{exc}"`，最终显示 "模型请求失败：模型请求失败：Connection error."
4. **流式失败回退非流式掩盖原因**：连接类错误会触发两次无效请求

### 代码修改
- **`core/llm/openai_client.py`**：
  - 新增 `_build_http_client()`：构建 httpx.AsyncClient，通过 `mounts={"all://127.0.0.1": None, "all://localhost": None}` 绕过代理直连 loopback
  - 新增 `_translate_exception()`：将 openai SDK 异常翻译为可操作中文（连接被拒绝/超时/401/404/429/5xx），提取 `__cause__` 中的真实原因
  - `AsyncOpenAI` 构造时传入自定义 `http_client`
  - `complete()`/`stream()` 异常改用 `_translate_exception()` 而非 `f"模型请求失败：{exc}"`
  - `aclose()` 同时关闭自定义 httpx client
- **`core/agent/engine.py`**：
  - `run()` 的 ErrorEvent 不再重复添加 "模型请求失败：" 前缀
  - `_stream_once()` 对连接类错误不回退到非流式（换一种请求方式不会改善连接问题）
- **`core/llm/diagnostics.py`**（新增）：连通性诊断模块，检查配置完整性、端口监听、代理检测、HTTP 探活，生成中文报告
- **`core/llm/__init__.py`**：导出 diagnostics 模块
- **`main.py`**：新增 `--doctor` CLI 参数
- **`tui/screens/chat_screen.py`**：新增 `/doctor` 命令；修复侧栏 base_url 硬编码为空
- **`tui/modals/help_modal.py`**：帮助弹窗补充 `/doctor` 命令
- **`tests/test_core.py`**：适配新的错误消息格式（不再检查 "模型请求失败" 前缀）

### 验证
- 21 个单元测试全部通过
- `--doctor` 诊断命令正确输出：端口 7863 连接被拒绝、HTTP 探活失败
